# fuse 💣

**画面の端で燃える導火線として時間を可視化する、楽しくて邪魔にならないタイマー。**

`fuse` は、プレゼンテーションや勉強会、その他集中したい作業の時間管理をサポートします。一度設定したらあとは見守るだけのシンプルな設計で、タスクへの集中を促します。

## 主な特徴

* **シンプルで直感的な設定**: 拡張機能のアイコンをクリックし、時間を入力してスタートするだけです。
* **ハードリミットとソフトリミット**:
    * **ハードリミット（必須）**: タイマーの総時間です。導火線全体の長さに対応します。
    * **ソフトリミット（任意）**: 時間が迫っていることを知らせる警告時間です。この時間を過ぎると、導火線の色が変わることで、視覚的に注意を促します。
* **画面下部への固定表示**: 導火線は常に画面の下部に表示されるため、ウェブコンテンツの邪魔になりません。
* **クリーンなアニメーション**: 導火線は片側から滑らかに燃えていくだけ。余計なエフェクトがなく、時間の経過をクリーンに伝えます。
* **小気味よいフィニッシュ**: 時間がゼロになると、導火線の終点で小さな爆発アニメーションが再生されます。💥
* **中断なしの集中設計**: 一度火をつけたら、停止やリセットはできません。この潔い仕様が、深い集中をサポートします。

## 使い方

1.  Chromeのツールバーにある **`fuse` のアイコン**をクリックします。
2.  ポップアップが表示されたら、**ハードリミット**の総時間を入力します。
3.  （任意）**ソフトリミット**の警告時間を入力します。
4.  **「スタート」**ボタンをクリックします。
5.  現在のタブの画面下部に導火線が現れ、後戻りできないカウントダウンが始まります！

## 開発環境

開発に必要なツール（Node.js 24 / just / zip / ImageMagick）は [Nix](https://nixos.org/) で管理しています。ホストに個別にインストールする必要はありません。

### 前提

- Nix（flakes 有効）
- [direnv](https://direnv.net/) + [nix-direnv](https://github.com/nix-community/nix-direnv)（任意・推奨）

### 使い方

direnv を使う場合は、初回のみ `direnv allow` を実行すると、以降はディレクトリに入るだけで環境が有効になります。direnv を使わない場合は `nix develop` でシェルに入ります。

ツールを追加・変更する場合は `flake.nix` の `packages` を編集してください。

### タスク

よく使う操作は [just](https://github.com/casey/just) のレシピにまとめています。`just` だけを実行すると一覧が表示されます。

| コマンド | 内容 |
|---|---|
| `just build` | 配布ファイルを `dist/extension/` にコピー |
| `just package` | ストア提出用の ZIP を `dist/` に作成 |
| `just clean` | 生成物を削除 |

### Chrome への読み込み

1. `just build` を実行します。
2. [chrome://extensions/](chrome://extensions/) で「デベロッパーモード」を有効にします。
3. 「パッケージ化されていない拡張機能を読み込む」から `dist/extension/` を選択します。

リポジトリのディレクトリをそのまま読み込むと、`.direnv/` なども拡張機能の一部として扱われ、不要なファイルについての警告が出ます。コードを変更したら `just build` を実行し、拡張機能を再読み込みしてください。
