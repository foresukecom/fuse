# fuse 💣

**画面の下で燃えていく導火線として時間を可視化する、楽しくて邪魔にならないタイマー。**

`fuse` は、プレゼンテーションや勉強会、その他集中したい作業の時間管理をサポートします。一度設定したらあとは見守るだけのシンプルな設計で、タスクへの集中を促します。

## 主な特徴

* **シンプルで直感的な設定**: 拡張機能のアイコンをクリックし、時間を入力してスタートするだけです。
* **画面下部への固定表示**: 導火線は画面の下部に表示され、クリックなどの操作を妨げません。
* **すべてのタブで表示**: タイマーは開いているすべてのタブに表示され、タブを切り替えても同じ残り時間が続きます。
* **3つのテーマ**: 💣 爆弾（火が導火線を進む）、🐕 犬と家（犬が家に帰る）、⛵ 船と島（船が島に向かう）から選べます。テーマは実行中でも切り替えられます。
* **残りわずかの合図**: 残り10秒になると、アイコンが揺れて時間が迫っていることを知らせます。
* **小気味よいフィニッシュ**: 時間がゼロになると、テーマに合わせた完了アニメーションとメッセージが表示されます。💥
* **いつでも停止**: ポップアップの「タイマー停止」か、タイマー表示の「×」で止められます。停止はすべてのタブに反映されます。

## 使い方

1.  Chromeのツールバーにある **`fuse` のアイコン**をクリックします。
2.  ポップアップでテーマを選び、時間（時:分:秒）を入力します。
3.  **「タイマー開始」**ボタンをクリックします。
4.  開いているすべてのタブの画面下部に導火線が現れ、カウントダウンが始まります。
5.  時間になると完了メッセージが表示されます。「×」か「タイマー停止」で消せます。

## 開発環境

開発に必要なツール（Node.js 24 / just / zip / ImageMagick）は [Nix](https://nixos.org/) で管理しています。ホストに個別にインストールする必要はありません。

### 前提

- Nix（flakes 有効）
- [direnv](https://direnv.net/) + [nix-direnv](https://github.com/nix-community/nix-direnv)（任意・推奨）

### 使い方

direnv を使う場合は、初回のみ `direnv allow` を実行すると、以降はディレクトリに入るだけで環境が有効になります。direnv を使わない場合は `nix develop` でシェルに入ります。

ツールを追加・変更する場合は `flake.nix` の `packages` を編集してください。

### タスク

よく使う操作は [just](https://github.com/casey/just) のレシピにまとめています。`just` だけを実行すると一覧が表示されます。

| コマンド | 内容 |
|---|---|
| `just setup` | 依存のインストール（Playwright 用の Chromium も取得） |
| `just build` | 配布ファイルを `dist/extension/` にコピー |
| `just test` | ビルドしてテストを実行 |
| `just package` | ストア提出用の ZIP を `dist/` に作成 |
| `just screenshots` | ストア用スクリーンショット（1280x800）を `store/` に作成 |
| `just icons` | `images/icon-source*.svg` から拡張機能のアイコンを再生成 |
| `just clean` | 生成物を削除 |

### Chrome への読み込み

1. `just build` を実行します。
2. [chrome://extensions/](chrome://extensions/) で「デベロッパーモード」を有効にします。
3. 「パッケージ化されていない拡張機能を読み込む」から `dist/extension/` を選択します。

リポジトリのディレクトリをそのまま読み込むと、`.direnv/` なども拡張機能の一部として扱われ、不要なファイルについての警告が出ます。コードを変更したら `just build` を実行し、拡張機能を再読み込みしてください。

## クレジット

テーマで使用しているアイコンのうち、`icons/dog.svg` は [Font Awesome Free 5](https://fontawesome.com/) の「dog」アイコンです（© Fonticons, Inc., [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)）。サイズ指定などの属性のみ変更しています。

それ以外のアイコン（`icons/*.svg`、`images/icon-source*.svg`）はこのリポジトリのために作成したものです。
